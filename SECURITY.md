# Security

Please report a suspected flaw in the signing, verification or proof code privately, by email to
`sovereign.systems007@gmail.com`, with `[security]` at the start of the subject. Don't open a public issue for it.

Say which package and version it affects (TypeScript, Python or Go), and include a receipt, key pair or proof that
shows the problem if you can; test keys only, never a key in real use.

The contact is also given in the specification (`packages/verifiable-receipts/SPEC.md`, Contact).
